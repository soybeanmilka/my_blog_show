前缀和 (Prefix Sum)

1 核心思想

前缀和是一种预处理技术，通过预先计算数组的前缀和，将区间求和查询从 $O(n)$ 优化到 $O(1)$。

定义： prefix[i] 表示数组前 i 个元素的和（从下标 1 开始）。

$$ \text{prefix}[i] = \sum_{k=0}^{i-1} \text{nums}[k] $$

区间和公式： $\text{sum}(l, r) = \text{prefix}[r+1] - \text{prefix}[l]$

// 核心：prefix[j] - prefix[i] = k  →  prefix[i] = prefix[j] - k
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> cnt;
    cnt[0] = 1;  // 空前缀
    int pre = 0, ans = 0;
    for (int x : nums) {
        pre += x;
        if (cnt.count(pre - k)) ans += cnt[pre - k];
        cnt[pre]++;
    }
    return ans;
}

6 注意事项

  1. 前缀和数组长度通常是 n+1，prefix[0] = 0，方便处理从头开始的区间
  2. 哈希表初始化 cnt[0] = 1（或 pos[0] = -1），表示空前缀
  3. 元素可能为负数时，前缀和不单调，不能用滑动窗口，要用哈希表
  4. 取模问题注意负数处理：(x % k + k) % k
  5. 二维前缀和注意容斥原理：加两次左上角
